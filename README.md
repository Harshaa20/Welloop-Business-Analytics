# Welloop Business Analytics

## Project Overview

This project analyzes interview data collected from youth athletes and coaches to support business decisions for Welloop.

The objective is to identify actionable insights that help determine whether a second-hand sports equipment exchange feature should be introduced, where a pilot should be launched, and what factors influence adoption readiness.

## Tools

- SQL (MySQL)
- Excel
- Power BI
- Python
